# פורטל זכויות עובדי המלונאות - מהדורת אילת (Hospitality Labor Rights Portal)

אפליקציית Web אינטראקטיבית, מודרנית ומותאמת מלאה ל-RTL ולמובייל, המנגישה את דיני העבודה בישראל. **הפורטל מתאים לכל סוגי העובדים במשק וכולל מידע מלא, מהימן ומעודכן שנכון לכולם**, לצד הרחבה ומיקוד ענפי ייעודי בעובדי המלונאות ובפרט באילת.

האפליקציה בנויה כ-Single Page Application (SPA) מתקדמת ב-React, TypeScript ו-Tailwind CSS, ומשלבת בין חוקי המגן הכלליים לכלל העובדים לבין ההסכם הקיבוצי הענפי במלונאות (2023–2026), נספח אילת הייעודי, הטבות מס ומגורים בעיר, ומחשבוני שכר ייעודיים. כוללת מעבר ייעודי בין **אזור עובדים** (פשוט, מונגש וממוקד אילת) לבין **אזור משאבי אנוש וחשבות שכר** (מעמיק ומשפטי).

---

## 🌟 תכונות מרכזיות (Core Features)

1. **הבהרה משפטית מחייבת (Legal Disclaimer):**
   - מודל קופץ (Modal) בפתיחה ראשונה הדורש אישור קריאה ותנאי שימוש (עם שמירת אישור ב-`localStorage`).
   - באנר עליון קבוע ורציף המדגיש כי הכלי נועד למטרות מידע והתארגנות אישית בלבד ואינו מהווה ייעוץ משפטי.
   - גישה בלחיצת כפתור להבהרה המלאה בכל רגע נתון.

2. **מאגר זכויות מובנה (Categories Grid):**
   - קטלוג של 11 קטגוריות ו-13 תחומי זכות מקיפים: פיצויי פיטורים, סעיף 14, חופשה שנתית, ימי מחלה, שעות נוספות, שכר מינימום ונוער, פנסיה וסעיף 45א, הודעה מוקדמת, דמי הבראה, עבודת נשים והורות, נסיעות ותלוש שכר, הטרדה מינית, בתי דין לעבודה והתיישנות.
   - כרטיסי מידע מעמיקים הכוללים: מקור החוק, שנת חקיקה, עקרונות יסוד, עדכוני 2026, מלכודות נפוצות וקישורים ישירים לאתר "כל זכות" ולמאגר נבו.

3. **יועץ שאלות ותרחישים (Interactive Q&A / Chat):**
   - ממשק שיחה אינטראקטיבי המעבד תרחישים מעשיים של עובדים (כגון: "פוטרתי אחרי 10 חודשים", "המעסיק מפריש 6% ולא 8.33%", "פיטורים בלי שימוע", "שעות נוספות בשבת", "דמי הבראה", "מחלת ילד").
   - מענה בעל מבנה אחיד: תקציר, מקור חוקי, הוראות החוק וכללי חישוב, מלכודות ואזהרות מיוחדות, וצעדים מעשיים מומלצים.
   - **מנגנון הגנה והפניה ל"כל זכות":** אם שאלה אינה מכוסה במאגר המאומת, המערכת מודיעה בשקיפות מלאה ומפנה ישירות לחיפוש באתר "כל זכות" (https://www.kolzchut.org.il/) למניעת הזיות.

4. **מחשבונים משפטיים אינטראקטיביים (Calculators):**
   - **מחשבון פיצויי פיטורים ובדיקת סעיף 14:** חישוב משכורת אחרונה × ותק, תקרת פטור ממס (13,750 ₪ לשנה ב-2026), בדיקת הפקדות 6% מול 8.33%, וסכום השלמת הפיצויים במזומן המגיע לעובד.
   - **מחשבון חופשה שנתית:** טבלת ותק מדויקת לפי חוק חופשה שנתית ותיקון 2016 (ימי ברוטו מול נטו לשבוע 5 או 6 ימים), ודגש על חריג צבירה במילואים/חירום ללא הסכמת מעסיק.
   - **מחשבון דמי הבראה 2026:** לפי התעריף המעודכן (451.50 ₪ בפרטי מ-18.8.2026), בדיקת השלמת 33.50 ₪ ליום אם שולם בחסר, וניכוי יום מילואים לפי הוראת שעה 2025-2026.
   - **מחשבון הודעה מוקדמת:** חישוב מדויק של ימי הודעה מוקדמת לעובד חודשי מול עובד שעתי/יומי.
   - **מחשבון שכר מינימום 2026:** תעריף 6,443.85 ₪ חודשי ו-35.40 ₪ שעתי למבוגר, וטבלת נוער עובד וחניכים (מחלק 173 שעות).

5. **חיפוש חכם (Smart Search):**
   - חיפוש מיידי לפי מילות מפתח, חוקים, תגיות ומלכודות.
   - תגיות חיפוש מהירות.
   - חיפוש ישיר ב"כל זכות" במידה ולא נמצאה תוצאה מקומית.

6. **חוקים, ערכאות והתיישנות (Laws Summary):**
   - טבלת השוואת זמני התיישנות (שכר 7 שנים, פדיון חופשה 3 שנים, הלנת שכר ופיצויים - 60 יום בלבד!).
   - סמכות בתי הדין האזוריים לעבודה (ולא תביעות קטנות) וערבות ביטוח לאומי בפירוק חברה.

## 🛠️ טכנולוגיות וארכיטקטורה

- **Frontend Framework:** React 19 + TypeScript
- **Styling & Design System:** Tailwind CSS (RTL logical properties: `ms-`, `me-`, `ps-`, `pe-`, start/end)
- **Icons:** Lucide React
- **Build Tool:** Vite
- **Deployment Target:** Vercel (מוגדר עם `vercel.json` לניתוב SPA חלק)

---

## 🚀 הוראות הרצה מקומית (Local Development)

```bash
# 1. התקנת תלויות
npm install

# 2. הרצת שרת פיתוח
npm run dev

# 3. בניית גרסת פרודקשן לבדיקה
npm run build
npm run preview
```

## ☁️ הוראות העלאה ל-Vercel (Deployment)

הפרויקט מוכן לחלוטין לפריסה אוטומטית ב-Vercel:

1. **אפשרות א': פריסה דרך Vercel CLI:**
   ```bash
   npx vercel
   ```
2. **אפשרות ב': חיבור למאגר GitHub / GitLab:**
   - דחפו (push) את הקוד למאגר גיט.
   - היכנסו ל-Vercel ובחרו ב-**Import Project**.
   - Vercel יזהה אוטומטית את Vite ויבצע את הפקודה `npm run build` אל תוך ספריית `dist/`.
   - קובץ ה-`vercel.json` המצורף מבטיח שכל הנתיבים והרענונים (F5) ינותבו בצורה מושלמת לדף ה-SPA.
